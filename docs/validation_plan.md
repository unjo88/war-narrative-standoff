# 검증 계획(v0.2, 투고 전 보강)

발표문 Ⅳ장 5절의 계획을 옮기고 표본 설계의 근거와 산출물 형식을 덧붙인다. 측정 결과는 저장소 v0.2에 공개한다.

## 1. 주석 일치도(Krippendorff's α)
- **표본**: 1597년 266항목 중 본문 5어절 이상인 230항목(정서어 있음 58 / 없음 172)에서 각 25개 = 50항목(무작위, 시드 20261121)
- **주석자**: 연구자(R1)와 연구자 외 1인(R2). 같은 주석 지침(정서 범주 정의, 행위자 표기, 부정 표현 처리)을 쓰고 서로 결과를 보지 않는다.
- **단위와 값**: 항목 × 상위 범주(상실·분노·의지·해소·불안)의 유무(명목형), 주된 범주(명목형)
- **판정**: α ≥ 0.800 확정 / 0.667 ≤ α < 0.800 잠정 / α < 0.667 범주 정의 수정 후 재측정 (Krippendorff, 2004)
- **층화 이유**: 정서어 없는 항목이 대부분이어서 무작위 표본에서는 α가 부풀려지거나 불안정해진다.
- **준비 완료(v0.1)**: 표본 ID `annotations/agreement_sample_ids.csv`(시드 20261121, 층 정보는 태깅 뒤 공개), 지침 `docs/annotation_guideline.md`, 계산 코드 `code/agreement.py`(참조 구현 krippendorff 패키지와 값 일치 확인)
- **v0.2 산출물**: 두 주석자의 판정값(번역문 없음), `aggregates/krippendorff_alpha.csv`, `aggregates/disagreements.csv`

## 2. 판독 정확도(문자 오류율, CER)
- **표본**: *난중일기* 1597년 20항목, *일리아스* 18권 100행(천병희 역·이준석 역 각각)
- **참값**: 연구자가 원본 쪽과 글자 단위로 대조해 확정한 텍스트(비공개 작업 코퍼스에 둔다)
- **측정**: 한글 글자 기준 편집 거리 / 참값 길이. 두 판독(내장 글자 정보, Tesseract 5)과 병합본 각각
- **비교**: 이미 공개한 두 판독 간 불일치율(`aggregates/ocr_disagreement.csv`)이 CER을 얼마나 잘 대신하는지
- **산출물**: `aggregates/cer_sample.csv`(표본 ID·글자 수·오류 수·CER만 공개, 텍스트는 비공개)

## 3. 통계적 불확실성(v0.1에서 시행)
- 블록 붓스트랩 5,000회, 95% 백분위 구간: `aggregates/bootstrap_ci.csv`
- *일리아스* 10행 블록 62개, *난중일기* 겹치는 64일
- 사전 v1·v2의 밀도 비 차이(0.13[−0.02, 0.33])도 함께 기록한다. 한쪽은 구간이 1을 넘고 다른 쪽은 넘지 않아도, 그 차이 자체가 유의하지 않을 수 있기 때문이다(Gelman & Stern, 2006).
- 구간은 블록·날짜가 서로 독립이라는 가정 아래의 값이다.
- 시드 고정(1·2·3)으로 같은 값이 재생산된다.
